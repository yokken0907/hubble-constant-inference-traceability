# Repository Content Policy

## Purpose

This repository contains materials that materially improve the inspectability, traceability, bounded reproducibility, provenance, and correction readiness of the associated Hubble-constant inference report.

## Inclusion criteria

A file may be included when it materially supports one or more of the following functions:

- mapping a registered statement to designated evidence;
- validating a published numerical value or table row;
- recording a public source, version, locator, or file identity;
- preserving an author-generated output used by a registered claim;
- documenting a bounded re-execution or implementation-diversity check;
- distinguishing historical, current, and corrected evidence states;
- enabling package-level integrity verification; or
- documenting scientific scope, limitations, and claim boundaries.

## Exclusion criteria

The repository excludes materials that do not materially improve those functions, including:

- internal development scratch files and transient logs;
- duplicate caches and generated bytecode;
- large third-party datasets, posterior archives, likelihood products, and raw observational releases that are not licensed or necessary for redistribution;
- unrelated follow-up studies;
- private credentials, personal operational records, and machine-specific paths; and
- redundant transport copies that add no traceability value.

Third-party materials are identified through source records, versions, filenames, byte sizes, hashes, or retrieval records where available, rather than redistributed by default.

## Version rule

Reader-facing documentation may be corrected in a later repository version without altering the fixed scientific archive baseline. Metadata-only versions must preserve registered scientific statements, numbers, validation records, replay records, tolerances, evidence hashes, classifications, and claim boundaries.

## Scientific boundary

Inclusion in this repository does not itself establish scientific correctness, causal attribution, external independent replication, expert endorsement, or resolution of the Hubble tension.
