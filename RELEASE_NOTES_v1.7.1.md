# Hubble Constant Inference Traceability v1.7.1

Version 1.7.1 is a non-scientific archive-interface and pre-publication packaging update.

## Release scope

This release:

- adds `TRACEABILITY_ARCHIVE_DESCRIPTION.pdf`, a bilingual description of the archive contents, reading order, integrity checks, and interpretation boundaries;
- excludes manuscript submission files before Jxiv publication, consistent with `REPOSITORY_CONTENT_POLICY.md`;
- updates active package, citation, release, and verifier metadata to v1.7.1; and
- regenerates the complete root manifest and SHA-256 closure.

The original publication records remain unchanged:

- original manuscript statements: `C001-C030`;
- original principal numerical results: `N001-N046`;
- later bounded validation: `V001 = COMPLETE_WITH_SCOPE`;
- replay records: `E001 = COMPLETE_WITH_SCOPE` and `E002 = COMPLETE_WITH_SCOPE`;
- scientific values, units, tolerances, scopes, and claim boundaries: unchanged.

## Interpretation boundary

This release does not add a causal claim, measurement correction, model-preference claim, new-physics claim, or Hubble-tension-resolution claim. V001, E001, and E002 remain bounded project-internal validation or replay records and are not external independent replication or reconstruction of the originating likelihoods, samplers, convergence assessment, or posterior-generation environments.

## Publication status

The package is assembled and verified locally. Creation of a remote Git tag, GitHub Release, persistent identifier, or Jxiv record is not performed or claimed by this package.
